# Drop the mascot here

Save the Kapibara Blyatovich art into **this folder**
(`website1/public/assets/`) with this exact filename:

| Filename | What it is |
|---|---|
| `kapibara.webp` | Kapibara Blyatovich — grumpy capybara in the "cykablyat" ushanka, full body, transparent or flat background |

The page already points at `/assets/kapibara.webp`. Once the file exists it
renders with no code changes — the grow, gulp and squash animations are driven
from the wrapper element, not the artwork.

`.png` works too; if you use PNG, tell me and I'll switch the reference.

## Memecoins

The coins fed to him are Robinhood-listed memecoins only:

| Filename | Coin |
|---|---|
| `coin-doge.webp` | DOGE |
| `coin-shib.webp` | SHIB |
| `coin-pepe.webp` | PEPE |
| `coin-bonk.webp` | BONK |
| `coin-wif.webp` | WIF |

Until these exist the page falls back to lettered coin discs.
